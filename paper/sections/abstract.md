# Abstract

Multi-point traversal path planning, where a mobile robot must visit a set of target points in an optimal order while navigating around obstacles, is a core problem in autonomous navigation with applications in autonomous shuttle services, logistics, and infrastructure inspection. The problem couples two interacting sub-problems: a geometric one of finding collision-free paths between pairs of points in cluttered environments, and a combinatorial one of determining the optimal visitation order, a variant of the Traveling Salesman Problem (TSP). Existing methods typically address only one sub-problem in isolation: TSP solvers assume unconstrained Euclidean distances, while path planners optimize only single-pair routes. This paper proposes a collaborative optimization framework that unifies both. The framework encodes obstacle constraints into a TSP cost matrix through an improved A* global planner based on Jump Point Search (JPS), which exploits grid symmetry to skip redundant node expansions, combined with a safety-aware path simplification procedure (corner extraction, greedy scanning, and intermediate-point exploration) and arc-length parameterized cubic spline smoothing. The resulting open TSP, with distinct fixed start and goal locations, is solved by an improved Ant Colony Optimization algorithm that converts the open TSP into a closed TSP via a virtual node method, and integrates Max-Min Ant System pheromone management, an Ant Colony System-style pseudo-random transition rule, and Variable Neighborhood Descent local search accelerated by a candidate list, with S-curve progressive scheduling and an adaptive stopping criterion. Extensive experiments on three test environments demonstrate that the JPS-based planner expands up to 83% fewer nodes and completes searches up to 17× faster than Dijkstra while producing shorter paths; parameter sensitivity analysis identifies a well-balanced default configuration; ablation studies reveal that VND local search and MMAS pheromone bounds are the two critical components for solution quality; and the proposed ACO solver achieves the optimal cost with a 97.5% hit rate on the kroB100 benchmark, outperforming standard ACO, GA, and SA by a substantial margin while maintaining exceptional reliability.

**Keywords:** multi-point traversal, path planning, Jump Point Search, Ant Colony Optimization, open Traveling Salesman Problem, obstacle avoidance, virtual node method.
