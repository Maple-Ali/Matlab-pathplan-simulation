# 6. Conclusion

This paper presented a collaborative optimization framework for obstacle-aware multi-point traversal path planning that integrates an improved A* global planner with an improved Ant Colony Optimization solver for the open Traveling Salesman Problem. The framework addresses a practical gap in the literature: traditional TSP research assumes unconstrained Euclidean distances, while standard path planning algorithms optimize only single-pair routes. By encoding obstacle constraints into a cost matrix via the global planner and solving the resulting open TSP via the ACO optimizer, the framework unifies geometric and combinatorial reasoning into a single pipeline.

On the path planning side, the adaptive exponential weighted heuristic (AEWH) provides a principled distance-dependent trade-off between search speed and path quality. Unlike constant-weight Weighted A*, AEWH decays the heuristic weight exponentially from $1 + \alpha$ at the start to near unity at the goal, achieving greedy exploration in open regions while recovering precision near the goal. The safety-distance-aware path simplification uses an exact point-to-cell-boundary distance computation to guarantee obstacle clearance during line-of-sight pruning, and the arc-length parameterized cubic spline smoothing converts the simplified polyline into a $C^2$-continuous trajectory suitable for physical robot execution.

On the TSP optimization side, the improved ACO solver incorporates five integrated mechanisms. The MMAS pheromone management with dynamic bounds prevents premature convergence and maintains exploration diversity. The ACS-style pseudo-random transition rule accelerates convergence through controlled greedy exploitation. The candidate-list-accelerated VND reduces local search complexity from $\mathcal{O}(K^2)$ to $\mathcal{O}(K \cdot k)$, making intensive neighborhood search practical for problem sizes exceeding 100 target points. The S-curve progressive scheduling gradually shifts the local search budget from exploration to exploitation across the iteration horizon. The adaptive stopping criterion based on population homogeneity and best-solution stagnation terminates the search when further improvement is unlikely, conserving computational resources.

Experimental results demonstrate the effectiveness of each component. The improved A* planner reduces expanded node counts compared to Dijkstra and standard A* while maintaining comparable path quality. The path post-processing pipeline reduces waypoint counts and produces smoother trajectories. On the TSPLIB kroA150 benchmark, the improved ACO solver achieves lower mean cost and tighter variance than baseline GA, SA, and standard ACO implementations. Ablation studies confirm that each mechanism—pseudo-random transition, VND local search, S-curve scheduling, candidate-list acceleration, and MMAS bounds—contributes independently to solution quality or computational efficiency. An end-to-end validation on a self-built obstacle-rich scenario demonstrates the framework's practical applicability to realistic autonomous navigation missions with distinct start and goal locations.

Several limitations of the current work suggest directions for future research. First, the framework assumes a static and fully known obstacle map; extending to dynamic environments where obstacles appear or move during the mission would require online replanning capabilities. Second, the map representation is limited to 2D grid maps; extending to 3D terrain with elevation constraints would broaden applicability to aerial and underwater vehicles. Third, the candidate list size $k$ and other ACO hyperparameters are fixed; adaptive or learning-based parameter tuning could further improve performance across diverse problem instances. Fourth, the framework currently addresses single-robot missions; extending to multi-robot cooperative multi-point traversal—where multiple robots share the target workload and must avoid inter-robot collisions—represents an important practical generalization. Finally, the computation of the full $\mathcal{O}(N^2)$ cost matrix becomes expensive for very large target sets; techniques such as distance oracle approximation or incremental cost refinement could mitigate this bottleneck.
