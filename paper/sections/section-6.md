# 6. Conclusion

This paper presented a collaborative optimization framework for obstacle-aware multi-point traversal path planning that integrates an improved A* global planner with an improved Ant Colony Optimization solver for the open Traveling Salesman Problem. The framework addresses a practical gap in the literature: traditional TSP research assumes unconstrained Euclidean distances, while standard path planning algorithms optimize only single-pair routes. By encoding obstacle constraints into a cost matrix via the global planner and solving the resulting open TSP via the ACO optimizer, the framework unifies geometric and combinatorial reasoning into a single pipeline.

On the path planning side, Jump Point Search (JPS) exploits the symmetry inherent in uniform-cost grid maps to prune redundant node expansions, expanding only jump points where the optimal path changes direction or encounters a forced choice. This reduces the search tree size dramatically in open environments while preserving path optimality. The safety-distance-aware path simplification operates in four steps (corner extraction, greedy forward scan, intermediate-point exploration, and path comparison), producing a minimal safe waypoint subset. The arc-length parameterized cubic spline smoothing converts the simplified polyline into a $C^2$-continuous trajectory suitable for physical robot execution.

On the TSP optimization side, the improved ACO solver incorporates six integrated mechanisms. The virtual node method converts the open TSP into a standard closed TSP, enabling start and goal nodes to participate fully in the pheromone model and local search. The MMAS pheromone management with dynamic bounds prevents premature convergence and maintains exploration diversity. The ACS-style pseudo-random transition rule accelerates convergence through controlled greedy exploitation. The candidate-list-accelerated VND reduces local search complexity from $\mathcal{O}(K^2)$ to $\mathcal{O}(K \cdot k)$, making intensive neighborhood search practical for problem sizes exceeding 100 target points. The S-curve progressive scheduling gradually shifts the local search budget from exploration to exploitation across the iteration horizon. The adaptive stopping criterion based on population homogeneity and best-solution stagnation terminates the search when further improvement is unlikely, conserving computational resources.

Experimental results demonstrate the effectiveness of each component. The JPS-based A* planner expands up to $83\%$ fewer nodes than Dijkstra ($48$ vs. $566$ on the kroB100 map) and completes the search up to $17\times$ faster ($11.85$ ms vs. $202.29$ ms on the corridor map), while the path post-processing pipeline further reduces path length below that of unmodified A* and Dijkstra. Parameter sensitivity analysis confirms that the default hyperparameters represent a well-balanced configuration, with the greedy probability $q_0$ and late-stage local search ratio $y_{\max}$ being the most sensitive parameters. Ablation studies reveal a clear component hierarchy: VND local search and MMAS pheromone bounds are the two pillars of solution quality (disabling either collapses the success rate from near $100\%$ to below $30\%$), while the pseudo-random transition rule, S-curve scheduling, and candidate list acceleration contribute primarily to convergence speed and computational efficiency. In the multi-point traversal comparison, the proposed MMAS-VND-CL solver achieves the optimal cost with a $97.5\%$ hit rate on the kroB100 benchmark (mean cost $22142.45$), outperforming the best baseline (standard ACO, mean cost $24435.83$) by $10.4\%$, while maintaining a standard deviation over $60\times$ smaller than GA, demonstrating both superior solution quality and exceptional reliability for obstacle-aware multi-point traversal path planning.

Several limitations of the current work suggest directions for future research. First, the framework assumes a static and fully known obstacle map; extending to dynamic environments where obstacles appear or move during the mission would require online replanning capabilities. Second, the map representation is limited to 2D grid maps; extending to 3D terrain with elevation constraints would broaden applicability to aerial and underwater vehicles. Third, the candidate list size $k$ and other ACO hyperparameters are fixed; adaptive or learning-based parameter tuning could further improve performance across diverse problem instances. Fourth, the framework currently addresses single-robot missions; extending to multi-robot cooperative multi-point traversal, where multiple robots share the target workload and must avoid inter-robot collisions, represents an important practical generalization. Finally, the computation of the full $\mathcal{O}(N^2)$ cost matrix becomes expensive for very large target sets; techniques such as distance oracle approximation or incremental cost refinement could mitigate this bottleneck.
