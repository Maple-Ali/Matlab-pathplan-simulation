# 1. Introduction

Multi-point traversal path planning is a fundamental problem in autonomous mobile robotics with applications spanning autonomous shuttle services, logistics warehouse management, infrastructure inspection, and search-and-rescue operations. In a typical mission, a robot departs from a designated start location, visits a set of intermediate target points to perform tasks (e.g., pick up passengers, inspect equipment, deliver items), and finally proceeds to a goal destination. The planner must solve two distinct but coupled sub-problems: (i) finding collision-free paths between consecutive points in a cluttered environment, and (ii) determining the optimal visitation order of the intermediate target points. The first sub-problem is geometric—it requires reasoning about obstacle geometry and path continuity in physical space. The second sub-problem is combinatorial—it is an instance of the Traveling Salesman Problem (TSP), a classic NP-hard optimization problem. These two sub-problems interact: the cost of traveling between any pair of points depends on the obstacles that lie between them, and the optimal visitation order depends on these pairwise costs.

Existing approaches to multi-point navigation typically address only one of these sub-problems in isolation. The vast body of TSP research assumes that pairwise costs are given by Euclidean distance or a known distance matrix, ignoring the fact that in obstacle-rich environments, the shortest collision-free path between two points may be significantly longer than the straight-line distance. Conversely, the path planning literature offers mature algorithms—A*, Dijkstra, Rapidly-exploring Random Trees (RRT), and their variants—that efficiently compute optimal or near-optimal collision-free paths between pairs of points in grid maps, but these planners do not optimize the visitation order of multiple target points. A small number of studies have explored obstacle-aware TSP variants (e.g., the TSP with obstacles, Dubins TSP) under specific geometric assumptions, but a unified, general-purpose framework that integrates a grid-based global planner with a high-performance TSP solver for obstacle-rich environments remains absent.

In this paper, we propose a collaborative optimization framework for obstacle-aware multi-point traversal path planning. The framework consists of two algorithmic layers connected by a precomputed cost matrix. The first layer is an improved A* global planner featuring an adaptive exponential weighted heuristic that accelerates search without sacrificing path quality, combined with a safety-distance-aware path simplification procedure and an arc-length parameterized cubic spline smoothing pipeline. The second layer is an improved Ant Colony Optimization (ACO) solver for the open TSP that converts the open TSP into a standard closed TSP via a virtual node (dummy node) method, enabling full exploitation of closed-TSP search operators. The solver integrates Max-Min Ant System (MMAS) pheromone management, an Ant Colony System (ACS)-style pseudo-random transition rule, and a Variable Neighborhood Descent (VND) local search engine accelerated by a $k$-nearest-neighbor candidate list, with progressive local search scheduling via an S-curve function and an adaptive stopping criterion.

The contributions of this work are structured on three levels:

1. **Problem-level contribution.** We formulate the obstacle-aware multi-point traversal problem as an integrated optimization task and propose a two-layer framework that encodes obstacle constraints into a TSP cost matrix via a global planner. This formulation bridges the gap between isolated path planning and unconstrained TSP research, making the framework applicable to real-world autonomous navigation missions where obstacles are present and the start and goal are distinct locations.

2. **Algorithm-collaboration-level contribution.** We introduce a path-simplification-aware cost computation mechanism: by applying safety-distance-aware path simplification before evaluating the cost-matrix entries, the TSP cost function more accurately reflects the true continuous-path length, enabling finer discrimination between alternative visitation orders. The modular architecture allows any grid planner and any TSP solver to be substituted into the respective layers.

3. **Component-level contribution.** On the path planning side, the adaptive exponential weighted heuristic provides a principled distance-dependent trade-off between search speed and optimality. On the TSP side, the virtual node method transforms the open TSP into a closed TSP, allowing start and goal nodes to participate fully in the pheromone model and local search. The candidate-list-accelerated VND reduces local search complexity from $\mathcal{O}(K^2)$ to $\mathcal{O}(K \cdot k)$, the S-curve progressive scheduling balances exploration and exploitation across the iteration budget, and the adaptive stopping mechanism prevents unnecessary computation. Each component is individually validated through ablation studies.
