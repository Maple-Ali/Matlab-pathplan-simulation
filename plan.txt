# 全向移动机器人多目标自主导航仿真系统设计方案

## 1. 系统概述

本项目在 MATLAB R2025b 环境下构建一个 2D 栅格地图中的移动机器人仿真系统。机器人需从起点出发，自动按最优顺序遍历所有目标点，最终到达终点。路径规划分为全局规划（包含 TSP 多目标排序）和局部动态避障两层。系统提供完整的 GUI 交互界面，支持地图编辑、算法选择、仿真控制和数据反馈。

---

## 2. 系统架构

采用**分层模块化**设计，自上而下分为：

- **表现层（GUI）**：负责用户交互与可视化
- **控制层（Simulation Manager）**：协调全局规划、局部规划、TSP 求解、碰撞检测等
- **算法层**：独立的路径规划与避障算法库
- **模型层**：地图、机器人、障碍物的数据模型

所有模块均以独立 `.m` 文件或类实现，互不耦合，仅通过明确接口调用。

## 3. 模块详细设计

### 3.1 数据模型模块

#### 3.1.1 `Map.m` - 地图类
- **属性**：
  - `size`：正方形边长（栅格数）
  - `grid`：矩阵，数据类型 `uint8`，0=自由空间，1=静态障碍，2=动态障碍（初始标记）
  - `dynamicObstacles`：`DynamicObstacle` 对象数组
- **方法**：
  - `Map(size)`：构造函数，初始化全零矩阵
  - `setStaticObstacle(rows, cols)`：批量设置静态障碍
  - `setDynamicObstacle(obs)`：添加动态障碍物
  - `isFree(row, col)`：检查栅格是否可通行（考虑动态障碍当前位置）
  - `updateDynamicObstacles(dt)`：更新所有动态障碍物位置
  - `getOccupancyGrid()`：返回当前时刻的占用栅格矩阵（静态+动态）

#### 3.1.2 `DynamicObstacle.m` - 动态障碍物类
- **属性**：
  - `startPos`：起始点 `[row, col]`（栅格索引）
  - `endPos`：终点 `[row, col]`
  - `speed`：移动速度（栅格/秒）
  - `currentPos`：当前位置 `[y, x]`（连续坐标，方便插值）
  - `direction`：1 或 -1
- **方法**：
  - `DynamicObstacle(startPos, endPos, speed)`
  - `update(dt)`：沿线段匀速移动，到达端点时反向。更新 `currentPos`
  - `getOccupiedGrids()`：返回当前占据的栅格索引（考虑障碍物尺寸，暂设占一个栅格）

#### 3.1.3 `OmnidirectionalRobot.m` - 全向移动机器人类
- **属性**：
  - `pos`：`[x, y]` 连续坐标
  - `vel`：`[vx, vy]` 当前速度
  - `maxSpeed`：最大线速度 (m/s，可映射为栅格/秒)
  - `maxAccel`：最大加速度
  - `radius`：机器人半径（用于碰撞检测）
  - `trajectory`：记录实际走过的路径点（用于可视化）
- **方法**：
  - `OmnidirectionalRobot(startPos, maxSpeed, radius)`
  - `applyVelocity(vx, vy, dt)`：用速度积分更新位置
  - `getState()`：返回当前位置和速度
  - `recordTrajectory()`：将当前位置追加到轨迹记录

### 3.2 算法模块

#### 3.2.1 全局路径规划算法（均提供统一接口）

**通用函数签名**：
```matlab
function path = AStar(map, startGrid, goalGrid, delay)
```
输入：地图对象、起点栅格索引、目标栅格索引、可视化延迟时间（0 表示不绘制）
输出：`N×2` 的路径点数组（栅格坐标 `[row, col]`）

**包含算法**：
- `AStar.m`：标准 A* 实现，启发式采用欧氏距离或曼哈顿距离
- `Dijkstra.m`：基于优先队列的 Dijkstra 搜索
- `RRT.m`：快速随机扩展树，步长可设，最大迭代次数可配置，连接检测需考虑障碍物

**全局路径后处理**：
- `SimplifyPath.m`：拐角裁剪算法（如三点一线且直线不穿障则删中间点）
- `SmoothPath.m`：三次样条插值平滑，可指定插值密度（每段插入点数）

#### 3.2.2 TSP 求解器

`TSPsolver.m`：
- 输入：起点、目标点集（数组）、终点、地图对象
- 内部逻辑：
  1. 调用全局规划算法计算所有点对之间的最短路径长度（成本矩阵）
  2. 使用动态规划（Held-Karp）或遗传算法求解最短访问顺序（起点固定为第一个，终点固定为最后一个，中间目标点自由排列）
  3. 返回有序的目标点序列，以及每两个连续点之间的全局路径（调用全局规划器获得）
- 支持通过参数选择全局规划算法类型（用于计算成本矩阵）

#### 3.2.3 局部路径规划算法

**通用函数签名**：
```matlab
function [vx, vy, predictTraj] = DWAPlanner(robot, localGoal, map, obstacles, dt, params)
```
参数：
- `robot`：当前机器人状态
- `localGoal`：全局路径上的前瞻点（连续坐标）
- `map`：地图对象，提供局部障碍信息
- `obstacles`：动态障碍物列表
- `dt`：控制周期
- `params`：结构体，包含算法参数

输出：速度指令 `(vx, vy)` 和可选的预测轨迹（用于可视化）

**包含算法**：
- `DWAPlanner.m`：动态窗口法，生成速度采样，评估朝向目标、速度、避障等
- `TEBPlanner.m`：简化版时间弹性带，在局部目标点之间优化一系列位姿，使用 MATLAB 优化工具箱或自定义简单求解
- `MPCPlanner.m`：模型预测控制，用机器人模型离散化，求解有限时域最优控制问题（可使用 `fmincon` 或二次规划简化）

> 初期 TEB 和 MPC 可只提供包含详细注释的框架，内部用简化方法替代，保证可运行。

### 3.3 仿真控制模块

`SimulationManager.m`：负责协调整个仿真流程，不作为类，而是一个主控脚本或函数。

**核心流程**：
1. 读取 GUI 设置（地图、算法选择、起始点/目标点/终点等）
2. 求解 TSP 路径（如果目标点 >1）
3. 对每个路径段：
   - 调全局规划器获得段路径
   - 简化、平滑（可选）
   - 将平滑路径作为参考轨迹
4. 开始执行阶段循环：
   - 从起点出发，依次访问每个目标点（TSP 顺序）+ 终点
   - 在每个目标点处停留 1 秒
   - 在移动过程中，循环调用局部规划器：
     a. 获取机器人周围感知范围内的障碍物信息
     b. 选取全局路径上的前瞻点作为局部目标
     c. 局部规划器计算速度指令
     d. 机器人执行速度，更新位置并记录轨迹
     e. 更新动态障碍物位置
     f. 碰撞检测（与静态、动态障碍物、地图边界），若碰撞则中止并报错
     g. 可视化更新（地图、机器人、实际路径、局部预测轨迹等）
   - 重规划触发条件（后期可选）：若连续 N 秒未能接近参考路径或局部目标，重新调用全局规划生成剩余路径
5. 仿真结束后，弹出数据展示界面

**关键参数传递**：
- 通过全局结构体 `simParams` 统一管理参数（如每步延迟、机器人速度、局部规划器参数等）

### 3.4 GUI 模块（使用 MATLAB App Designer）

#### 3.4.1 主界面 `MainUI.mlapp`
- **左侧：地图编辑区**
  - 嵌入 `UIAxes`，显示正方形栅格地图，支持鼠标交互
  - 编辑模式按钮组（单选）：设置起点、添加目标点、设置终点、添加静态障碍、添加动态障碍、删除对象
  - 操作时，点击地图栅格执行相应编辑，并实时更新显示
  - 动态障碍物添加：点击两个栅格定义往复线段的端点
  - 提供“加载预设地图”下拉菜单，内置几种典型地图
  - 地图大小设置（编辑框或下拉选择，如 20×20、30×30 等），修改后重置地图
- **右侧：控制面板**
  - **全局规划算法选择**：下拉菜单（A*、Dijkstra、RRT）
  - **局部规划算法选择**：下拉菜单（DWA、TEB、MPC）
  - **后处理选项**：复选框“启用拐角裁剪”、“启用路径平滑”
  - **仿真速度控制**：编辑框“每步延迟时间(秒)”，默认 0.05
  - **按钮**：“开始仿真”、“重置地图”、“退出”
- **状态栏**：显示当前操作提示或仿真状态

#### 3.4.2 可视化窗口 `VisualizationUI.mlapp`
- 在仿真开始时自动弹出（或由主界面按钮打开）
- 包含一个 `UIAxes`，实时显示：
  - 栅格地图（静态和动态障碍物）
  - 机器人当前位置（圆形，方向指示可选）
  - 已走过的实际路径（某种颜色细线）
  - 全局规划路径：原始规划路径、简化后路径、平滑后路径（分别用不同颜色细线显示，在规划阶段结束后立即绘制）
  - 局部规划器的预测轨迹（如 DWA 的轨迹簇，用浅色虚线）
  - 动态障碍物的移动标记
- 坐标轴固定正方形，自适应地图大小

#### 3.4.3 数据展示界面 `DataViewerUI.mlapp`
- 仿真结束后弹出（或可通过主界面按钮打开）
- 显示文本信息（使用 `UITable` 或标签）：
  - 全局规划算法名称及耗时
  - 路径简化前后的路径长度（栅格距离或欧氏距离）
  - 平滑前后的路径长度
  - 总仿真时间、机器人行驶距离、是否发生碰撞
  - TSP 求解耗时、目标访问顺序
  - 其他统计数据（可选）

## 4. 数据流与接口

### 4.1 仿真启动数据流

```
主界面设置 → 收集参数至 simParams 结构体
→ SimulationManager(simParams)
   → Map 初始化，加入静态/动态障碍
   → 若目标点 >1 : TSPsolver 求解顺序 → 对每段调用 GlobalPlanner → 路径后处理
   → 进入执行循环
       → 局部规划器 (Robot, LocalGoal, Map) → 速度 → Robot.move()
       → Map.updateDynamicObstacles()
       → 碰撞检测
       → 可视化更新
   → 仿真结束 → 数据显示界面
```

### 4.2 碰撞检测接口

`checkCollision(robotPos, robotRadius, map)` ：
- 检查机器人圆域是否与任何静态障碍栅格或动态障碍物当前占据的栅格重叠
- 返回布尔值

## 5. 可视化与动态搜索绘制设计

### 5.1 全局规划算法可视化
- 各算法函数接收一个可选的 `delay` 参数
- 当 `delay > 0` 时，在每次扩展节点（Dijkstra/A*）或生成新节点（RRT）后，通过 `drawnow` 和 `pause(delay)` 更新地图显示
- 显示方法：在可视化窗口的同一个坐标轴上，绘制半透明的探索区域（如 Dijkstra 用 `scatter` 绘制已访问节点，RRT 用 `plot` 绘制树枝）
- 所有绘制均使用“持久图形对象”方法，避免重绘整个地图导致闪烁

### 5.2 局部规划可视化
- DWA：在每个控制周期绘制预测轨迹簇，保留上一周期的轨迹需先清除（使用单独的图形句柄）
- TEB/MPC：可绘制优化后的局部路径（如一段曲线）

### 5.3 路径区分颜色方案
- 原始全局规划路径：红色细线
- 简化后路径：蓝色细线
- 平滑后路径：绿色细线
- 实际机器人轨迹：黑色粗线（或深灰色）
- 动态障碍物：品红色方块，移动时更新位置
- 静态障碍物：黑色方格
- 起点：绿色实心圆
- 目标点：蓝色实心圆
- 终点：红色实心圆

## 7. 关键实现注意事项（供向智能体提问时强调）

1. **坐标系统一**：所有内部计算使用栅格索引 `(row, col)`，绘图时转为连续坐标 `(x, y)`。建议规定：栅格 `(r,c)` 中心连续坐标为 `(c-0.5, r-0.5)`。
2. **动态障碍物与地图更新**：全局规划基于静态地图执行；局部规划时，用地图的 `getOccupancyGrid` 获取实时障碍物信息（含动态障碍）。
3. **TSP 实现**：当目标点 ≤5 个时，可用全排列枚举；数量多时，建议用遗传算法或蚁群算法简化实现，智能体需提供注释说明。
4. **局部规划前瞻点选择**：在平滑后的全局路径上，选择与机器人一定前向距离（如 1 米）的点作为局部目标，如果路径段结束则选路径终点。
5. **可视化窗口绘图性能**：采用 `set` 更新图形对象属性，而不是反复 `cla`；只在必要时清除动态元素（如预测轨迹）。
6. **模块化测试**：每个算法文件应可在 MATLAB 命令行单独测试，提供简单的测试用例注释在文件底部。

## 8. 可扩展性与后期迭代方向

- **重规划机制**：当机器人长时间卡住或偏离路径过大，触发全局重规划（仅重新规划剩余路段）。
- **多机器人支持**：架构可扩展为多机器人协同。
- **更丰富的动态障碍行为**：如随机游走、避让机器人等。
- **性能分析报告**：自动生成规划时间、路径质量对比图表。
